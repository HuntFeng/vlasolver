# 2D Orbital-MotionLimited (OML) Sheath (Full Two-Species)

A **full two-species** (electron + ion) Vlasov-Poisson simulation of a plasma sheath forming around a circular dielectric dust.

## Physics

- **Domain**: quarter domain $[0, 20]\lambda_D \times [0, 20]\lambda_D$ in $(x, y)$ with the dust at the origin; by mirror symmetry this represents the full $[-20, 20]^2\lambda_D$ box at a quarter of the cost.
- **Normalization**: $T_i/T_e = 1$, $m_i/m_e = 100$
- **Boundary conditions**: symmetry planes at $x = 0$ and $y = 0$ (specular reflection for $f$, even reflection for $\phi$); Maxwellian injection and Dirichlet potential (fixed to 0) at the right and top walls.
- **Initial state** (`[init] model`): `oml` (default) starts from the 2D cylindrical OML solution: $\phi(r)$, the surface charge $\sigma = -\epsilon\,\phi'(a)$, and both species as $A_s e^{-E/T_s}$ on the OML-allowed part of velocity space (from the reservoir, $E \ge 0$; outgoing only if reflected before reaching the dust). `boltzmann` is the older start: guessed exponential sheath and Boltzmann electrons, with ions controlled by `trapped_ion_free`.
- **Diagnostic** `ni_bound`: density of bound ions ($E < 0$). These cannot exist in OML theory; a nonzero value measures the trapped population generated by the scheme.
- **Charging dust**: Dust is dielectric with $\epsilon=5$ and surface charge accumulates as it absorbs plasma.

## Build

```bash
cmake -B build && cmake --build build --target sheath_oml
```

## Run

```bash
# OML profile for the oml start (once, or whenever the parameters change)
uv run python examples/sheath_oml/sheath_oml.py --write-init examples/sheath_oml/oml_init.csv
build/sheath_oml examples/sheath_oml/input.ini
```
